Design the Question Edit screen.

Goal:
Allow the author to edit an open question while clearly showing editability constraints.

Layout:
- Global app shell
- Compact page header
- Current question status area
- Lightweight editor form

Required fields:
- Title
- Body
- Tags
- Visibility

Required workflow rules to express:
- Only the author can edit
- Once resolved and locked, body editing is not allowed
- Admins and owners must not see UI that implies they can edit another user's body content

Required states:
- Editable open question
- Locked resolved question
- Permission denied

Design emphasis:
- Close to Question Create in structure
- Slightly more contextual and state-aware
- Strict permission clarity
