Slackのチャンネル一覧はどこで確認できますか？

山田 太郎

投稿日: 2024-05-11 14:20

プロジェクトごとに作成されたSlackの全チャンネルを網羅的に確認する方法を探しています。サイドバーに表示されているもの以外にも、アーカイブされていないすべての公開チャンネルを見たいのですが、どのメニューからアクセスできますか？

解決時のスナップショット

verified ベストアンサー
佐藤 健一 2024-05-11 15:45
Slackの画面左上にある「チャンネル」セクションの横にある「＋」ボタンをクリックし、「チャンネルを閲覧する」を選択してください。これにより、参加していないものも含め、組織内のすべての公開チャンネルを検索・一覧表示できます。

history その他の当時の回答 (1)

鈴木 美咲 2024-05-11 15:10

ショートカットキー `Cmd + Shift + L` (Mac) または `Ctrl + Shift + L` (Windows) でもチャンネル一覧を開けますよ！

解決後の追加の議論

田中 恵 2024-05-13 09:12

追加の情報ですが、特定の名前の規則（例：proj_xxx）でチャンネルが運用されている場合、検索バーにそのプレフィックスを入力すると、より効率的に見つけられますね。
