新入社員向けオンボーディング手順

1. はじめに

本ドキュメントは、株式会社ナレッジ・インフラの新入社員が最初の30日間で完了すべき基本的な手順をまとめたものです。不明点がある場合は、各自のメンターに相談してください。

2. ツールセットアップ

初日の午前中までに以下のツールのアクセス権を確認し、セットアップを完了させてください。

  • Slack: 勤怠連絡およびプロジェクトコミュニケーションに使用します。
  • Notion: 全社的なwikiとして利用されています。
  • GitHub: エンジニア職の方は、社内組織への招待を確認してください。
  • 社内ナレッジポータル: (Rev 3 追加項目) 以下のURLからログイン設定を行ってください。 https://portal.knowledge-infra.internal

3. セキュリティ研修

入社後3日以内にe-ラーニング形式のセキュリティ研修を受講する必要があります。研修URLおよび受講完了報告フォームについては、情報システム部からのメールを参照してください。
