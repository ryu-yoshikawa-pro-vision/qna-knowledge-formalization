新入社員向けオンボーディング手順

「新しく入社したメンバーがスムーズに業務を開始するための基本的な手順とチェックリストです。」

1. 準備フェーズ

入社日までに、以下の環境構築と物理的な準備を完了させてください。これらは情報システム部および総務部との連携が必要です。

  • check_circle アカウント発行： Slack, Notion, GitHub, AWS, および社内基幹システムのアカウントを事前に作成し、招待メールを送信します。
  • check_circle ハードウェア： PC（MacBook Pro/Air選択可）、モニター、周辺機器をデスクに配置済みであることを確認。

2. 初日オリエンテーション

初日は「歓迎されている実感」と「会社文化の理解」を最優先事項とします。

AM: 事務手続き
  • ・雇用契約、保険手続きの最終確認
  • ・オフィスツアーと各設備案内
  • ・PCセットアップと初期ログイン
PM: チームビルディング
  • ・ウェルカムランチ（メンター同席）
  • ・プロダクトビジョンの説明
  • ・1on1（期待値のすり合わせ）

3. 最初の1週間のゴール

最初の1週間で、以下の「Small Win（小さな成功）」を体験することを目指します。

Team Collaboration
早期のチーム馴染みが定着率の鍵となります
