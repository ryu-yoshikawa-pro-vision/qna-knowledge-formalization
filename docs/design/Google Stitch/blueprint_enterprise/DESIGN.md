# Design System: Knowledge Infrastructure

## 1. クリエイティブ・ノーススター（設計指針）
**"The Architectural Archivist"（知の構造家）**

本デザインシステムは、単なるナレッジ管理ツールではなく、企業の知的資本を支える「インフラ」としての風格を目指します。目指すのは、無機質なグリッドの羅列ではなく、信頼感と静寂が共存するエディトリアル（編集的）な体験です。

- **意図的なアシンメトリー:** 左サイドバーの堅牢な構造に対し、メインコンテンツエリアでは余白を大胆に使い、情報の重要度に応じたリズムを生み出します。
- **トナリティによる境界:** 従来の1pxの境界線を排除し、色の階層（Tonal Layering）によって情報の区切りを表現します。
- **権威あるタイポグラフィ:** Manropeのモダンな幾何学性とInterの実用性を組み合わせ、専門性と読みやすさを両立させます。

---

## 2. カラーシステム (Colors)

このシステムでは、境界線（Border）に頼らず、背景色のシフトによって「面」を定義します。

### カラーパレット
- **Primary (`#002045` / `primary`):** 叡智と安定の象徴。重要なアクションとブランドの核。
- **Primary Container (`#1A365D` / `primary_container`):** ナビゲーションの背景や、深い集中を促すエリアに使用。
- **Background (`#F7F9FB` / `background`):** 視覚的ノイズを最小限に抑えた、キャンバスとしての薄いグレー。
- **Surface Tiers:**
  - `surface_container_lowest`: 純粋な白（`#FFFFFF`）。メインのカードやエディタに使用。
  - `surface_container_low`: セクションの背景に使用。
  - `surface_container_highest`: ツールバーなど、より前面に浮き上がらせる要素に使用。

### デザインの原則：ノーライン・ルール
本システムでは、セクションを区切るための「1pxのベタ塗り境界線」を原則禁止します。
- **面による分離:** 背景色（`background`）の上に、わずかに明るい色のカード（`surface_container_lowest`）を置くことで境界を表現します。
- **グラスモルフィズム:** 浮遊する要素（ポップオーバー等）には、`surface` カラーに 80% 程度の透過度と `backdrop-blur(20px)` を適用し、情報の奥行きを演出します。

---

## 3. タイポグラフィ (Typography)

情報の密度を制御し、ユーザーを「知」へと導く階層構造。

- **Display & Headline (Manrope):** `display-lg` から `headline-sm` に使用。セクションの開始や、力強いステートメントを表現します。
- **Title & Body (Inter):** `title-lg` から `body-sm` に使用。日本語の読みやすさを最適化するため、行間（Leading）は `1.6` 〜 `1.8` と広めに設定します。

| Role | Font Family | Size | Usage |
| :--- | :--- | :--- | :--- |
| **Headline-LG** | Manrope | 2.0rem | ページタイトル・重要なセクション見出し |
| **Title-MD** | Inter (Medium) | 1.125rem | カードタイトル・コンテンツの小見出し |
| **Body-MD** | Inter (Regular) | 0.875rem | 本文テキスト・標準的なナレッジ記事 |
| **Label-SM** | Inter (Semi-Bold) | 0.6875rem | メタデータ・キャプション・バッジ |

## 4. 奥行きとレイヤー (Elevation & Depth)

「影」を作るのではなく、「光」と「重なり」を設計します。

- **トナール・レイヤリング:** `surface_container_low` の上に `surface_container_lowest` を配置することで、自然な浮き上がりを作ります。
- **アンビエント・シャドウ:** 浮遊感が必要な場合、影は極めて拡散させます。
  - *Setting:* `box-shadow: 0 12px 40px rgba(0, 27, 60, 0.05);`（青みを含んだ薄い影）
- **ゴースト・ボーダー:** アクセシビリティの観点で境界線が必要な場合は、`outline_variant` を 10-20% の不透明度で使用します。100% 不透明な線は「ノイズ」とみなします。

## 5. コンポーネント (Components)

### バッジとステータス (Badges & States)
ナレッジのライフサイクルを直感的に伝えるため、特定の色相を採用します。

- **Formal / 確定:** `primary_fixed` の背景に `on_primary_fixed` のテキスト。
- **Unreviewed / 未確認:** `tertiary_fixed`（アンバー）。注意を引くが、警告ではない。
- **Changes Requested / 修正依頼:** `error_container`（オレンジ・レッド）。アクションが必要な状態。
- **Resolved / 解決済み:** グリーン（`#2D6A4F` 等の深めの緑）。
- **Draft / 下書き:** `secondary_fixed_dim`（ミュートされたブルーグレー）。
- **Archived / アーカイブ:** `surface_dim`（グレー）。

### ボタン (Buttons)
- **Primary:** 角丸 `md (0.375rem)`、背景は `primary`。グラデーション（`primary` → `primary_container`）をわずかに施し、プロダクトの「魂」を表現します。
- **Secondary:** 背景なし、`outline` を `ghost border` で適用。

### リストとカード (Lists & Cards)
- **区切り線の禁止:** リスト項目間に `border-bottom` を引くのをやめ、垂直方向の余白（`spacing-md`）または、ホバー時の `surface_variant` への背景変化で項目を識別させます。

## 6. Do's and Don'ts (運用の心得)

### ✅ Do's
- **余白を恐れない:** 知識を扱う場所には、思考のための「呼吸空間」が必要です。
- **階層を意識したネスト:** コンテナの中にコンテナを置く際は、必ず Tonal Tier を一段階変えてください。
- **文脈に応じたフォント選択:** 数字や専門用語が並ぶ場所では Inter を、ユーザーを歓迎する場所では Manrope を強調してください。

### ❌ Don'ts
- **高コントラストな境界線の多用:** 画面が「グリッドの檻」に見えてしまい、ユーザーの集中を妨げます。
- **純粋な黒（#000000）の使用:** 常に `on_surface`（`#191C1E`）を使用し、視覚的な柔らかさを維持してください。
- **デフォルトのシャドウ:** ツールが自動生成するような、濃く短い影は、システムの「プレミアム感」を損ないます。

---
**Director's Note:**
このデザインシステムは「完成」ではなく「出発点」です。常に、そのデザインが「ユーザーの思考を助けているか、あるいは邪魔をしていないか」を自問してください。ナレッジ・インフラストラクチャは、静かで、しかし揺るぎない知の基盤であるべきです。
