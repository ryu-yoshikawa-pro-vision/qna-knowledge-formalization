Design the screen for creating an edit draft from an existing formal knowledge item.

Goal:
Protect the current formal version while allowing the original author to start a proposed revision.

Required content:
- Compact summary of the current formal knowledge item
- Status context showing that the current version remains formal and unchanged
- Primary action to create an edit draft
- Warning or blocking state if an unfinished edit draft already exists

Important constraints to express visually:
- Only the original author can create this draft
- Only one active edit draft may exist at a time
- The formal version remains the source of truth until a revised version is approved and applied

Design emphasis:
- Protective and deliberate
- Minimal but very clear
- The user must understand they are starting a proposal, not editing the live formal version directly
