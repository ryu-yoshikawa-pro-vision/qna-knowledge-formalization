Design the invitation acceptance screen shown after a user opens an invitation link and signs in.

Goal:
Allow the user to review the invitation details and accept access to a workspace with confidence.

Required content:
- Workspace name
- Invited email address
- Invited role
- Invitation status
- Expiration information
- Primary accept action
- Secondary guidance for invalid or expired cases

Required states:
- Valid invitation ready to accept
- Email mismatch
- Expired invitation
- Already accepted
- Revoked invitation

Design rules:
- Keep the screen lightweight and decisive
- Make the invitation information easy to verify
- Use restrained status messaging, not alarming visuals
- This should feel like a secure access confirmation screen for an internal system
