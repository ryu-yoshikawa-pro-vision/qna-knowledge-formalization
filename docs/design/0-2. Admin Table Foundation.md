Design an Admin Table Foundation reference screen for the desktop web app.

Goal:
Create a reusable reference screen that defines the table-based management UI used across admin screens.
This should establish the operational visual language for Member Management and Tag Management.

Critical rule:
This is not a final feature screen.
It is a table foundation board with realistic admin usage examples.
It must feel like a quiet, trustworthy operational system.

The screen should include these sections:

1. Admin Page Shell Preview
Show a realistic signed-in admin page using:
- Top header
- Left sidebar navigation
- Page header
- Filter area
- Table area
- Row actions area

2. Base Table Pattern
Show the reusable base table structure including:
- Header row
- Body rows
- Status column
- Actions column
- Sortable headers
- Checkbox selection only if subtle and operationally justified
- Hover state
- Selected row state
- Focused row or keyboard focus state
- Empty table state
- Loading table skeleton
- Error table state

3. Row Action Patterns
Show reusable row-level action patterns for:
- Standard action
- Secondary action
- Overflow menu action
- Destructive action
- Confirmation-triggering action

4. Status and Safety Patterns
Show how status appears inside tables using consistent badges and subdued visual emphasis.
Also show:
- destructive action warning treatment
- confirmation pattern
- archived / inactive row treatment
- disabled or unavailable action treatment, only where truly necessary

5. Member Management Example
Show a realistic example table for member management with columns such as:
- Name
- Email
- Role
- Membership State
- Join Date
- Actions

Also show compact sub-sections or tab patterns for:
- Members
- Invitations
- Join Requests

6. Tag Management Example
Show a realistic example table for tag management with columns such as:
- Tag Name
- Normalized Name
- Status
- Usage Count
- Creator
- Updated Date
- Actions

Also show examples of governance-related actions:
- Rename
- Merge
- Archive

7. Admin Filter and Utility Patterns
Show reusable admin-focused controls for:
- Filter bar
- Search field
- Status filter
- Bulk-safe operations area
- Clear action hierarchy for table management

Design emphasis:
- Table readability over decorative styling
- Strong operational trust
- Quiet enterprise admin experience
- Easy row comparison
- Safe destructive action handling
- Consistent with the main app shell, but clearly more operational
- Do not make it feel like a data-heavy legacy back office
- Do not make it overly soft or card-based
