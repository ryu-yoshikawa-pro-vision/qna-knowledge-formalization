Keep the same design system, spacing, typography, color rules, status badge rules, layout structure, component language, and enterprise SaaS tone established in previous screens.

This product is knowledge-first, state-driven, role-aware, and operationally clear.
Knowledge has higher visual priority than Q&A.
Avoid social or community-platform styling.
Do not introduce playful UI patterns, engagement mechanics, or decorative visual trends.
Use a calm blue-based enterprise interface with strong readability and structured information hierarchy.

Design the Bookmarks screen.

Goal:
Allow users to revisit saved knowledge items and questions in a clean personal library view.

Layout:
- Global app shell
- Page header
- Filter controls
- Bookmark result list

Default behavior:
- Show most recently bookmarked items first

Each bookmarked item should show:
- Item type: knowledge or question
- Title
- Tags
- Updated date
- Creator
- Status badge
- Archived badge if applicable
- Remove bookmark action
- Navigate-to-detail action

Required filters:
- Item type
- Archived included / excluded

Design emphasis:
- Calm personal reference space
- Structured and easy to scan
- Consistent with list patterns already established elsewhere
