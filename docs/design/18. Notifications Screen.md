This product is knowledge-first, state-driven, role-aware, and operationally clear.

Design the Notifications screen.

Goal:
Allow users to review personal notifications efficiently without confusing this screen with the review work queue.

Layout:
- Global app shell
- Page header
- Filter controls
- Compact notification list

Each notification item should show:
- Notification type
- Actor
- Notification message
- Target link
- Read / unread state
- Created timestamp

Required actions:
- Mark as read
- Bulk mark as read

Required filters:
- Unread only
- Notification type

Design emphasis:
- Functional and compact
- Easy to scan
- Lower operational weight than the Review Queue
- Quiet personal inbox feel, not a feed
