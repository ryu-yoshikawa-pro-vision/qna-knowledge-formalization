Design the join request screen for a user who wants to request access to an existing workspace.

Goal:
Allow users to send or review a join request in a simple and trustworthy workflow.

Required content:
- Workspace name
- Domain or workspace identification information
- Short explanation of the join request process
- Optional comment field
- Primary action to send request
- Secondary action to withdraw request when applicable

Required states:
- Ready to submit
- Request already sent
- Request withdrawn
- Request approved
- Request rejected

Design rules:
- Keep the form compact and calm
- Make status understandable at a glance
- The screen should feel administrative and low-friction
